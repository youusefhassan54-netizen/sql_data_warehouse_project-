# 📌 Project Requirements

## Building the Data Warehouse (Data Engineering)

### Objective

Develop a modern Data Warehouse using SQL Server to consolidate sales data from multiple source systems, enabling business intelligence and data-driven decision-making.

### Specifications

- Import data from ERP and CRM systems.
- Perform data cleaning and quality validation.
- Integrate multiple data sources.
- Design a Star Schema.
- Build Fact and Dimension tables.
- Create ETL pipelines.
- Implement business rules.
- Optimize query performance.
- Document the complete data model.
